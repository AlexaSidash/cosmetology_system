# Cosmetology Clinic Management System

A web-based system for managing daily operations of a cosmetology/aesthetic clinic.

## Features

- 📋 **Client Management** - Profiles with contact info, medical notes, and treatment history
- 📅 **Appointment Scheduling** - Calendar view with reminders and status tracking
- 💅 **Service Catalog** - Manage services, prices, and duration
- 👩‍⚕️ **Staff Management** - Schedules, commission tracking, and performance reports
- 📸 **Treatment Photos** - Before/after photo history for clients

## Tech Stack

- Backend: Python / Django
- Database: PostgreSQL
- Frontend: HTML, CSS, JavaScript
